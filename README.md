# FUND-ANALYSIS-SKILL

用**巴菲特**和**查理·芒格**的价值投资理念分析一只基金，输出**小白也能看懂**的单文件 HTML 报告。

一个 AI Agent Skill，适用于 WorkBuddy / OpenClaw / Claude Code 等支持 Skill 机制的客户端。

---

## 它解决什么问题

市面上的基金分析要么是一堆看不懂的指标（夏普比率、信息比率、下行捕获率……），要么是一堆没有信息量的废话（「业绩承压，静待花开」）。

这个 Skill 做两件事：

1. **用价值投资框架问对问题** —— 不罗列指标，而是回答「巴菲特会怎么看这笔投资」
2. **把结论翻译成人话** —— 目标读者是完全不懂金融的普通人

设计原则是**结论深刻、表达简单**，不是把内容做浅。芒格本人就是这么讲话的。

举个报告里的实际例子：

> **最大回撤 -38.41%** = 最惨的时候，你的 100 块变成 **61.6 块**。
> 而且要涨回 100 块，得赚 **62.3%**，不是 38.41%——**亏钱和回本从来不对称**。

## 分析框架

### 巴菲特的四把尺子

| 尺子 | 落到基金上问什么 | 小白翻译 |
|---|---|---|
| **能力圈** | 这只基金到底买了什么？ | 你知道自己的钱被拿去干什么了吗？ |
| **护城河** | 重仓股有定价权吗？还是纯周期股？ | 这些公司能悄悄涨价而客户不跑吗？ |
| **安全边际** | 当前估值处在历史什么位置？ | 现在是打折价还是溢价买入？ |
| **长期主义** | 波动能否承受？回本要涨多少？ | 你能拿住十年不慌吗？ |

### 芒格的三件武器

| 武器 | 落到基金上问什么 | 小白翻译 |
|---|---|---|
| **逆向思维** | 不问怎么赚钱，问怎么会亏钱 | 这笔投资最惨会惨成什么样？ |
| **多元思维模型** | 不同板块用不同逻辑（白酒看心理学，养猪看生物学） | 不同的钱要用不同的逻辑算 |
| **避免愚蠢** | 这只基金最容易让人犯什么错？ | 买它的人通常怎么亏的？ |

### 综合评分（0~100）

| 维度 | 权重 |
|---|---|
| 能力圈清晰度 | 20% |
| 护城河质量 | 20% |
| 安全边际 | 20% |
| 长期持有性 | 15% |
| 最坏情况可承受度 | 15% |
| 费率友好度 | 10% |

评分**必须给出扣分理由**。数据缺失的维度不给分、不填 0，而是从权重中剔除并重新归一化。

### 「杀利润 / 杀估值 / 还估值债」判别

同样是「跌了 40%」，性质可以完全不同——这是安全边际维度最需要的证据，也是本 Skill 相对普通指标罗列的核心增量：

| 股价 | PE | 利润 | 结论 |
|---|---|---|---|
| 跌 | **反升** | 崩 | ⚠️ **杀利润**：跌了但没变便宜，最危险 |
| 平/小涨 | 压缩 | 涨 | ✅ **还估值债**：赚钱靠盈利而非炒作 |
| 跌 | **创新低** | 稳 | 💡 **杀估值**：基本面没崩，崩的是情绪 |

实测样例（恒生科技指数，PE 取 30 只成分股中位数）：

| 年份 | 收盘 | PE 中位 | 归母净利中位 |
|---|---|---|---|
| 2021 | 5671 (-32.7%) | 22.6 | 24.3 亿港元 |
| 2022 | 4129 (-27.2%) | **33.1** ⚠️ | 20.8 亿（12 家亏损） |
| 2023 | 3764 (-8.8%) | 19.1 | 59.6 亿（+187%） |
| 2024 | 4468 (+18.7%) | 20.4 | **71.7 亿** |
| 2025 | 5516 (+23.5%) | 20.4 | 53.3 亿 |
| 26至今 | 4198 (-23.9%) | **17.6** ★五年最低 | 年报未出 |

2022 年指数跌 27% 而 PE 反而升到 33.1，是因为**利润塌得比股价快**——那年「便宜」是错觉。而 2026 年这次 PE 降到五年最低、利润中位数仍高于 21/22 年、亏损家数更少，属**杀估值而非杀利润**。

## 数据源

采用**多通道**设计，缺少商业数据授权时自动降级，保证随时可用。

### 方案 A：恒生聚源 MCP（数据最全）

唯一能拿到场外基金专有数据的通道：A/C 份额净值序列、**同类排名分位**、**夏普比率**、持有人结构。

需申请 `JY_API_KEY`（[恒生聚源数据地图](https://www.gildata.com/products/datamap)）：

```bash
mcporter config add jy-financedata-api  --url "https://api.gildata.com/mcp-servers/aidata-assistant-srv-api?token=<你的KEY>"
mcporter config add jy-financedata-tool --url "https://api.gildata.com/mcp-servers/aidata-assistant-srv-tool?token=<你的KEY>"
```

### 方案 B：westock CLI（无需鉴权，自动降级）

按**母 ETF / 标的指数**口径分析。拿得到概况、费率、各周期收益与回撤、重仓股权重、52周分位、PE/PB、基金经理履历；**拿不到**同类排名与夏普比率等场外专有指标。

```bash
westock search <名称> --type etf     # 定位代码
westock etf profile  <code>          # 概况、费率、经理、跟踪指数
westock etf overview <code>          # 各周期收益与回撤、估值历史分位
westock etf holdings <code>          # 前 20 大重仓（复数 holdings）
westock quote        <code>          # 现价、52周高低、PE/PB、内外盘
westock kline <code> --period month --limit 14
westock news   <code> --limit 8      # 近期动态
```

**取历年估值 / 利润序列**（用于上面的判别框架）：

```bash
westock quote <30只成分股> --date 2024-12-31        # 历史日行情自带 PE/PB/市值
westock finance <代码,最多10个> --type income --limit 24
```

`finance` 硬约束：**一次最多 10 个代码**、有限流（分批间隔 20 秒可过）、`--limit` 是**期数不是年数**（回溯 5 个年报需 ≥24）。

降级时报告顶部会强制显示**黄色口径警示条**，说明数据替代与全部缺失项。完整命令表与实测坑见 [`references/fund-data-sources.md`](references/fund-data-sources.md)。

### 方案 C：天天基金公开接口（2026-11 新增）

场外开放式基金与 QDII-LOF **不在 westock 行情库**（例 320011 诺安中小盘精选混合A、
160213 国泰纳斯达克100），需要真实净值序列时也走这里。请求需带 `User-Agent` 与对应 `Referer`。

```bash
curl -s -H "User-Agent: Mozilla/5.0" -H "Referer: https://fund.eastmoney.com/" \
  https://fund.eastmoney.com/pingzhongdata/<code>.js     # 净值/规模/经理/equityReturn
curl -s -H "Referer: https://fundf10.eastmoney.com/" \
  https://fundf10.eastmoney.com/jbgk_<code>.html        # 费率/规模/基准
```

**两条硬规则**：

1. **净值必须先复权重建**。分红或份额折算会让单位净值突然跳变——510310 在 2024-09-19
   单位净值 1.5977 → 3.2021（名义 +100.42%），但当日真实涨跌只有 +0.16%。
   用 `equityReturn` 累乘还原，再换算到当前口径，才能算「五年净值中位数」。
2. **折溢价率先确认有没有场内份额**。用东财 searchapi 看 `QuoteID`：
   同时有 `0.<code>`（Fund）与 `150.<code>`（OTCFUND）才是真 LOF；
   只有 OTCFUND 一条时没有场内价，折溢价率**数学上无法计算**，必须写清查证过程与对用户的实际影响。

完整端点表、失效端点清单与复权代码见 [`references/fund-data-sources.md`](references/fund-data-sources.md)，
实战踩坑记录见 [`references/case-studies.md`](references/case-studies.md)。

## 数据纪律（硬性红线）

- ❌ **不编数据**。拿不到就写「⚠️ 数据缺失 + 原因」
- ❌ **不用 0 冒充真实值**。接口返回 0 常常是缺失，不是真值
- ❌ **不给买卖指令**（不给目标价、不说「买入/卖出」）
- ❌ **不掩盖坏消息**。亏了就说亏了
- ❌ **不堆术语不解释**
- ✅ 可以给「适合谁 / 不适合谁 / 注意什么 / 持有多久」的适配性判断

### 禁用词表

以下表述一律不准出现在报告中，因为它们不传递任何信息：

> 业绩承压ㆍ静待花开ㆍ长期看好ㆍ逢低布局ㆍ震荡蓄势

## 报告结构（九块）

顺序是刻意设计的：**先给数字、再给解读**。用户第一反应是自己看数字再验证你的判断，先给数字是建立信任；倒过来会让人觉得你在替他下结论。

```
① 顶部卡片：基金名 / 代码 / 综合评分 / 一句话结论（降级时置顶黄色警示条）
② 关键指标速览：8 张 KPI 卡，每张带历史分位横条 + 大白话判语
③ 近五年变化：股价 / PE / 利润中位数 / 复权净值趋势 四组图（第四张用虚线标出五年净值中位数）
④ 「先说结论」：3~5 条大白话要点
⑤ 巴菲特四把尺子：四张卡片（结论 + 数据 + 评级图标）
⑥ 芒格三件武器：逆向思维 / 多元思维 / 避免愚蠢
⑦ 数据看图说话：走势 SVG + 重仓股条形 + 各周期收益红绿柱
⑧ 「这基金适合谁」：✅适合 / ⚠️谨慎 / ❌不适合 三类人群
⑨ 底部：数据来源、时间戳、缺失项清单、免责声明
```

## 报告样式

- 单文件 HTML，**CSS/JS 全内联，零外部依赖**，断网可正常打开
- 图表为**纯内联 SVG**（价格折线、重仓股条形、涨跌柱）
- 浅色主题，移动端自适应
- **中国股市配色**：涨 = 红 `#e63946`，跌 = 绿 `#2a9d8f`（与欧美相反）
- 货币符号 `¥`
- 术语解释块用浅黄底与正文区分

## 交付前自检

生成报告后跑一遍，基础四项必须全过：

```bash
grep -c -E 'src="http|href="http|cdn\.' report.html                    # 外部依赖 = 0
grep -c -E '业绩承压|静待花开|逢低布局|震荡蓄势|长期看好' report.html    # 禁用词 = 0
grep -o 'class="term"' report.html | wc -l                             # 术语解释块 ≥ 5
grep -o 'e63946' report.html | wc -l                                   # 涨红跌绿未用反
```

2026-11 起再加四项：**HTML 标签配平**、**SVG 坐标落在 viewBox 内**、
**图上标注极值与曲线采样点一致**、**浏览器对单个图表元素截图核对**。
完整清单见 [`references/html-report-template.md`](references/html-report-template.md)。

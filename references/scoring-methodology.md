# 巴菲特·芒格价值评分方法论

总分 100 分。**评分必须给出扣分理由，不能只给数字。**

## 权重分配

| 维度 | 权重 | 对应理念 |
|---|---|---|
| 能力圈清晰度 | 20% | 巴菲特：不投看不懂的生意 |
| 护城河质量 | 20% | 巴菲特：被护城河保护的城堡 |
| 安全边际 | 20% | 巴菲特：四毛买一块 |
| 长期持有性 | 15% | 巴菲特：不想持有十年就别持有十分钟 |
| 最坏情况可承受度 | 15% | 芒格：反过来想 |
| 费率友好度 | 10% | 巴菲特：成本是复利的敌人 |

---

## 1. 能力圈清晰度（20 分）

衡量「普通人能否一句话说清这只基金靠什么赚钱」。

| 得分 | 标准 |
|---|---|
| 18~20 | 单一清晰赛道，一句话能说清（如「买白酒龙头」「跟踪沪深300」） |
| 14~17 | 主题明确但含2~3 套不相关逻辑（如必需消费=白酒+养殖） |
| 8~13 | 名称与实际持仓存在误导（如「消费」实际不含可选消费） |
| 0~7 | 策略黑箱、频繁风格漂移、持仓看不懂 |

**扣分要点**：名字容易让人误解→ 直接扣 5分以上并在报告里明确警告。

## 2. 护城河质量（20 分）

看**重仓股**是否有定价权，而非看基金本身。

| 得分 | 标准 |
|---|---|
| 18~20 | 重仓股普遍有品牌/牌照/网络效应，能悄悄涨价（如高端白酒、龙头调味品） |
| 14~17 | 部分有护城河，部分是纯竞争性行业 |
| 8~13 | 以周期股/同质化产品为主（如养殖、化工、航运） |
| 0~7 | 概念股、无盈利支撑、题材驱动 |

**判断技巧**：问「这家公司提价 10%，客户会跑吗？」不会跑 = 有护城河。

## 3. 安全边际（20 分）

| 得分 | 标准 |
|---|---|
| 18~20 | PE/PB 处历史 20% 分位以下，52周分位 < 25% |
| 14~17 | 历史 20%~40% 分位，估值合理偏低 |
| 10~13 | 历史 40%~60% 分位，估值中性 |
| 5~9 | 历史 60%~80% 分位，偏贵 |
| 0~4 | 历史 80% 分位以上，明显泡沫 |

**必须同时看**：绝对估值（PE/PB）+ 相对位置（52周分位、距高点跌幅）。
**注意**：低估值 ≠ 便宜。周期股在盈利高点时 PE 很低，这是陷阱，要在报告中说明。

## 4. 长期持有性（15 分）

| 得分 | 标准 |
|---|---|
| 13~15 | 波动温和（近3年最大回撤 < 20%），赛道长坡厚雪，经理稳定 |
| 9~12 | 回撤 20%~35%，需要一定心理承受力 |
| 5~8 | 回撤 35%~50%，多数人拿不住 |
| 0~4 | 回撤 > 50%，或经理频繁更换、有清盘风险 |

**回本算法必须写进报告**：回撤 X% 后需上涨 `X/(1-X)` 才能回本。
例：跌 38% → 需涨 61.3% 回本（不是 38%）。

## 5. 最坏情况可承受度（15 分，芒格逆向思维）

不问能赚多少，问**最惨会怎样**。

| 得分 | 标准 |
|---|---|
| 13~15 | 最坏情况可推演且有下限（宽基指数、必需消费），不会归零 |
| 9~12 | 最坏情况明确但幅度大（单一行业主题） |
| 5~8 | 存在结构性风险（单一政策依赖、单一大客户、高杠杆） |
| 0~4 | 有本金永久损失可能（杠杆基金、单一新兴市场、退市风险标的） |

**推演三问**：① 历史最惨发生过什么？② 那个情境会重演吗？③ 重演时你会不会割在底部？

## 6. 费率友好度（10 分）

| 得分 | 标准 |
|---|---|
| 9~10 | 综合费率 ≤ 0.25%/年（宽基 ETF 水平） |
| 7~8 | 0.25%~0.60%/年（行业 ETF 常见水平） |
| 5~6 | 0.60%~1.20%/年 |
| 2~4 | 1.20%~1.80%/年（主动权益常见） |
| 0~1 | > 1.80%/年，或申购费 ≥1.5% 且无优惠 |

**必须提醒**：A 类（前端申购费）适合持有 1 年以上；C 类（销售服务费）适合 1 年以内。
若有场内 ETF 可直接买且折溢价接近 0，需明确告知**直接买 ETF 更省申购费**。

## 总分档位与表述

| 总分 | 档位 | 报告中的大白话表述 |
|---|---|---|
| 85~100 | 优秀 | 「难得的好东西，问题只在于买入价格」 |
| 70~84 | 良好 | 「基本靠得住，但有明确的短板要盯着」 |
| 55~69 | 中性 | 「不算坏，但也没什么特别理由非买它」 |
| 40~54 | 存疑 | 「问题比亮点多，除非你很清楚自己在干什么」 |
| 0~39 | 回避 | 「不建议普通人碰」 |

## 数据缺失时的处理

-某维度关键数据缺失 → **不给分，标注「⚠️ 无法评分（数据缺失：原因）」**
- 总分按**实际可评维度的权重重新归一化**，并在报告中注明「本次评分基于 X% 权重覆盖」
- **严禁**用 0 分或估算值填充缺失维度——那会误导读者
